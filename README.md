# Side Sheet Notes

Side Sheet Notes は、Google Chromeのサイドバー上で手軽にメモ入力・データ整理が行えるスプレッドシート型のメモ帳拡張機能です。  
シンプルなUIで素早い入力を可能にし、入力データはブラウザに自動保存されます。作成したデータはCSV形式でのコピーやファイル出力が可能です。

## 🚀 利用シーン

- **Webブラウジング中の簡易メモ・データ集計**
  ブラウザの画面を切り替えることなく、サイドバー上で表形式のメモやリストを素早く作成・編集できます。
- **データ入力作業の一次受け**
  Web上の情報（ID・URL・担当者・ステータス等）を一時的に整理し、一括でCSVファイルとして書き出したりクリップボードへコピーしてExcel等へ貼り付けることができます。
- **定型フォーマットのテンプレートデータ保持**
  よく使う項目名や入力形式を保持しておき、いつでも素早く参照・追加・クリアできます。


## ✨ 主な機能と仕様

### 1. テーブル操作・編集
- **スプレッドシート型入力**
  セルを直接クリックしてテキストを入力できます（自動ローカル保存対応）。
- **セル内改行の制限**
  データ構造を崩さないよう、セル内での `Enter` キーによる改行は無効化されています。クリップボードからの貼り付け時も自動で改行が除外されます。
- **キーボードナビゲーション（Tab拡張）**
  最終行・最終列のセルで `Tab` キーを押すと、自動的に下に新しい行が挿入され、先頭セルにフォーカスが移動します。

### 2. コンテキストメニュー（右クリック操作）
表内の任意のセルや行番号を右クリックすることで、以下の操作が行えます。
- **行の挿入**: 選択したセルの「上」または「下」に行を挿入
- **行の削除**: 選択中（複数選択可）の行を一括削除（※最低1行は維持する安全ガード付き）
- **列の挿入**: 選択したセルの「左」または「右」に列を挿入
- **列の削除**: 選択中の列を削除（※最低1列は維持）
- **空白セルの補完**: 未入力（空白）セルに対して、任意の文字列（例: `-` や `N/A`）を一括入力

### 3. 行の範囲選択
- **行番号（`#` 列）クリック**: 対象行を選択
- **`Shift` + クリック**: 範囲内の行を一括選択
- **`Ctrl`（Macは `Cmd`） + クリック**: 複数行を個別選択・解除

### 4. データ連携・管理（ツールバー）
- **一括クリア（ゴミ箱アイコン）**: 確認ダイアログを表示の上、データを初期状態（1行×3列）にリセット
- **CSVコピー（コピーアイコン）**: 現在の表データをCSVフォーマットでクリップボードにコピー
- **CSVダウンロード（ダウンロードアイコン）**: UTF-8（BOM付き）のCSVファイルとしてローカルにダウンロード

## 🛠️ 使用方法

### インストール手順（ローカル読み込み）

1. 本リポジトリ（またはプロジェクトフォルダ `side-sheet-notes`）をローカルに準備します。
2. ディレクトリ内に標準の `bootstrap.min.css`（`css/`）および `bootstrap.bundle.min.js`（`js/`）が配置されていることを確認します。
3. Google Chromeを開き、アドレスバーに `chrome://extensions/` を入力してアクセスします。
4. 画面右上の **「デベロッパー モード」** をオンにします。
5. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、`side-sheet-notes/dev` フォルダを選択します。

### 基本操作

1. **サイドバーの起動**
   Chromeのツールバーにある `Side Sheet Notes` の拡張機能アイコンをクリックすると、サイドバーが開きます。
2. **データの入力**
   セルをクリックしてテキストを入力します。入力した内容は即時に自動保存されます。
3. **行・列の調整**
   セルまたは行番号を右クリックし、コンテキストメニューから行・列の挿入や削除を行います。
4. **データの出力**
   ヘッダー右上のボタンから「CSVコピー」または「CSVダウンロード」を選択してデータを抽出します。


## 📁 プロジェクト構成

```text
side-sheet-notes/
├── manifest.json            # Chrome拡張機能マニフェスト (Manifest V3)
├── background.js            # Service Worker (アイコンクリックでのサイドバー起動制御)
├── sidepanel.html           # サイドバー画面構造
├── css/
│   ├── bootstrap.min.css    # Bootstrap 5 (ローカル同梱)
│   └── style.css            # スタイル定義
└── js/
    ├── bootstrap.bundle.min.js # Bootstrap JS (ローカル同梱)
    └── sidepanel.js         # シート操作・ストレージ・CSV処理ロジック
```
## 🔒 セキュリティ・プライバシー
- 外部接続なし（オフライン動作）: CDN等の外部通信を一切行わないため、セキュリティ要件の厳しい企業・組織環境でも安心して利用できます。
- ローカル管理: 入力されたデータはブラウザ内のローカルストレージ（chrome.storage.local）にのみ保存され、外部サーバーへ送信されることはありません。
